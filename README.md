# Aagaaz Institute

Flutter app for Aagaaz Institute students. Sign in with an Indian mobile number, then browse UPSC and MPPSC courses and live classes.

This build is a local demo. The one-time code step accepts any 6-digit code, and live video is a classroom preview until a class stream is connected.

## Run

Install Flutter 3.50 or newer, then from this folder:

```bash
flutter pub get
flutter run
```

## Sign in

Enter a 10-digit mobile number starting with 6, 7, 8, or 9, then any 6-digit code.
